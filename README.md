# السلاح الذي لا يُرى — نسخة إعداد للنشر

نسخة تحريرية مستقلة عن المصدر السابق. **ليست منشورة ولم تجتز البوابة الرسمية بعد.**

## ما تحقّق

- فصل الادعاءات عن الوقائع في قضية إيركوتسك، مع تصحيح الفقرة وفق تحديث منظمة الصحة العالمية 10 أكتوبر والمركز الأوروبي 12 أكتوبر 2026.
- الروابط الأساسية في صفحة المصادر، واللوحات المرئية موسومة بأنها رسوم تعبيرية غير وثائقية.
- تجميع ملفات الموقع للعمل دون إطار برمجي أو خدمات خط خارجية.

## ما يمنع النشر حتى يُنجَز على جهازك

1. مرفقات الخطوط غير مشمولة في هذه الحزمة عمداً. يسحبها `prepare-and-publish.sh` من مستودعي `middle-east-power-trap` و`cosmic-mind` المعتمدين، حسب ترخيص SIL OFL.
2. أصل العقاب الرسمي غير مضمّن. يسحبه السكربت من `Kakramah.github.io/images/eagle-emblem-metal.svg` ولا يرسم بديلاً.
3. تشغيل `بوابة-الويب.sh` الرسمية إلزامي، وأي رسوب يوقف السكربت قبل النشر.
4. تحتاج صلاحية GitHub CLI مفعّلة على جهازك، ثم التحقق الفعلي من رابط Pages العام.

## التشغيل

فكّ الحزمة داخل `~/khaldoun-projects/`، ثم افتح Terminal داخل مجلد `hidden-biological-threat` ونفّذ:

```bash
bash prepare-and-publish.sh
```

لا يعدّل السكربت أيّاً من مستودعات المصادر. وينشئ المستودع الجديد على `main` في أول رفع فقط، ولا يدمج أو يحذف أو ينشر شيئاً إذا فشل الفحص. لا يحدّث بوابة مشاريعك الرئيسية.
